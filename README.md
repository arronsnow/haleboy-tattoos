# Haleboy Tattoos

Website for Haleboy ([@haleboy.tattoos](https://www.instagram.com/haleboy.tattoos/)) at I Love You Tattoo, Maryville, TN.

The site lives in [`site/`](site/): an Astro app deployed to Cloudflare Workers, with an admin for the gallery, designs, featured work and site text. See [`site/README.md`](site/README.md) for setup and deployment.

```sh
npm --prefix site install
npm run dev   # http://localhost:4321
```
